# Bee Airlines EFB

Electronic flight bag for flight simulation (A321LR / A350-900). Open `index.html` through GitHub Pages and add it to the iPad home screen.

Put your ATC notes sheet in this folder as `atc-notes.pdf` and every new flight opens a copy of it.

Airport ground layouts: (c) OpenStreetMap contributors, ODbL 1.0. Live METAR: metar.vatsim.net. Not for real-world operational use.
