# Bee Airlines EFB

Electronic flight bag for flight simulation (A321LR / A350-900, ATC24 and MSFS 2024). Open it through GitHub Pages and add it to the iPad home screen.

Put your ATC notes sheet in this folder as `atc-notes.pdf` and every new flight opens a copy of it.
